A GitHub-compatible git forge built by an AI agent for the "Build a GitHub-compatible git forge" bounty. Implements the git smart HTTP protocol (v0/v2), REST issues/pulls/repos, GraphQL, MCP, and git operations, with byte-deterministic state.

## Run it

```sh
node --experimental-strip-types main.ts
```

Serves on the port given by `PORT` (default 3000). Set `MAKEFUN_SHOP_TOKEN` for shop endpoints.
